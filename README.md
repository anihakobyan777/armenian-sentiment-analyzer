# 🛍️ Market Intelligence AI Pro

Այս գործիքը նախատեսված է էլեկտրոնային առևտրի հարթակների (Amazon, Ozon և այլն) մեկնաբանությունների ավտոմատ վերլուծության համար։

## 🚀 Ֆունկցիաներ
- **Scraping:** Տվյալների հավաքագրում Selenium-ի միջոցով։
- **ML Sentiment Analysis:** Օգտագործում է Logistic Regression՝ հասկանալու համար մեկնաբանության տոնայնությունը։
- **Gamification:** XP և Level համակարգ օգտատերերի համար։
- **Visuals:** Գրաֆիկական վերլուծություն Plotly-ի միջոցով։
