# AI-Powered E-commerce Intelligence Tool 🇦🇲

Այս գործիքը նախատեսված է հայաստանյան օգտատերերի համար՝ վերլուծելու ապրանքների մեկնաբանությունները (Wildberries, Ozon, Temu, Amazon, AliExpress) օգտագործելով Google Gemini AI:

## ✨ Հիմնական ֆունկցիաները
- **Smart Sentiment Analysis:** Հասկանում է հայերեն, ռուսերեն և հայատառ լատիներեն (translit):
- **Buyer/Seller Modes:** Առանձնացված գործիքներ գնորդների և վաճառողների համար:
- **Gamification:** XP համակարգ և մակարդակներ (Levels)՝ օգտատերերի ակտիվությունը խթանելու համար:
- **Cross-Platform Price Comparison:** Գների համեմատություն տարբեր հարթակներում:
- **AI Summary:** Ապրանքի դրական և բացասական կողմերի ավտոմատ ամփոփում:

## 🚀 Ինչպես միացնել
1. Տեղադրել գրադարանները: `pip install -r requirements.txt`
2. Ստանալ Gemini API Key-ը [Google AI Studio](https://aistudio.google.com/)-ից:
3. Տեղադրել API Key-ը `app.py` ֆայլի մեջ:
4. Աշխատեցնել: `streamlit run app.py`

## 🛠 Տեխնոլոգիաներ
- Streamlit (Frontend)
- Google Gemini AI (NLP Analysis)
- Plotly (Data Visualization)
- Selenium (Data Scraping - Upcoming)
